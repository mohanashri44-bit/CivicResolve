
# CivicResolve
### AI-Assisted Civic Grievance Management and Infrastructure Monitoring System

## Project Overview
CivicResolve is a proposed digital platform developed to improve civic infrastructure complaint management through digital reporting, engineering-based assessment, priority classification and transparent complaint tracking.

## Objectives
- Simplify public infrastructure complaint registration.
- Identify and classify infrastructure defects.
- Assess defect severity using engineering principles.
- Prioritise complaints based on severity and location.
- Improve complaint tracking and resolution monitoring.

## Key Modules
1. Citizen Complaint Registration
2. Infrastructure Defect Classification
3. Engineering-Based Severity Assessment
4. Duplicate Complaint Detection
5. Municipal Authority Dashboard
6. Complaint Status Tracking

## Proposed Technologies
- Frontend: Flutter / React
- Backend: Firebase
- Database: Cloud Firestore
- AI Integration: Gemini API
- Mapping: OpenStreetMap

## Application Scope
The initial prototype focuses on potholes, drainage blockages and streetlight failures.

## Project Status
Academic project – Prototype development.

## Expected Outcome
A structured and transparent approach to civic infrastructure maintenance through digital complaint management and engineering-based prioritisation.
