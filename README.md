CivicResolve – AI-Assisted Civic Grievance Management System

Project Overview

CivicResolve is a web-based civic grievance management prototype designed to help citizens report public issues, track complaint status, and view complaint details through a simple dashboard.

Problem Statement

Traditional civic complaint systems may involve delays, limited transparency, and difficulties in tracking complaint progress. Citizens need a simple and accessible way to report public issues.

Proposed Solution

CivicResolve provides a digital platform where citizens can register complaints, select issue categories, provide location details, and track complaint status. A dashboard displays complaint statistics and allows complaints to be marked as resolved.

Key Features

- Citizen complaint registration
- Civic issue category selection
- Location-based complaint reporting
- Complaint ID generation
- Complaint status tracking
- Dashboard with complaint statistics
- Rule-based complaint priority classification
- Mark complaints as resolved

Technology Stack

- HTML – Website structure
- CSS – Styling and responsive layout
- JavaScript – Functionality and complaint management
- Browser Local Storage – Saving complaint data

Working Process

1. Citizen enters complaint details.
2. The system generates a unique complaint ID.
3. A rule-based mechanism assigns a priority level.
4. Complaint details are displayed on the dashboard.
5. Citizens can track complaint status using the complaint ID.
6. Complaints can be marked as resolved through the dashboard.

Testing

The prototype was tested for:

- Complaint registration
- Complaint ID generation
- Complaint tracking
- Dashboard statistics
- Complaint status updates
- Mobile layout

Project Limitations

- Complaint data is stored in browser Local Storage.
- Data is not shared across different devices or users.
- The current priority classification uses predefined rules, not an integrated AI model.
- The dashboard does not have authority authentication or a centralized backend.

Expected Outcome

To demonstrate how a simple digital grievance management system can improve complaint registration, tracking, and visibility of civic issues.

Project Type

Prototype – Web Application
